# 更新日志

## v3.0.x

### v3.0.8

- 添加自定义表格字段 changeset
- 添加自定义表格序号属性

- 重构依赖系统，支持流式处理
- 优化 dependOn 性能

### v2.1.14

- 优化表格单元格渲染

- 新增 `outDependOn` 支持外部依赖
- 改进 `otherKey` 的多值支持
- 优化表单验证性能

- 初始版本
